# 驯兽师 · Tamer

> 把规则写成代码，把说话交给模型。

一个每天只做四件事的个人计划引擎：

1. **排三个时间块** —— 每天从项目池里抽 2 主线 + 1 支线，不是让模型自由发挥；
2. **接着昨天的断点** —— 今天第一块的动作，来自你昨天停下的地方；
3. **给新想法设门槛** —— 出现三次才准升级成项目，名额满了必须替换；
4. **在快烂尾时拦一下** —— 进度靠里程碑判定，不靠感觉。

针对三种可复现的失控：**被新想法带走、断掉后回不来、接近完成却烂尾。**

| 晚间验收回写 | `plan review --block 1 --done --note …` | 完成 |

## 怎么跑

零依赖，Node 24 直接跑：

```bash
node core/src/cli.ts plan new --date 2026-10-23
node core/src/cli.ts plan render --morning --date 2026-10-23
node --test core/test
```

数据是纯 JSON，放在 `data/`（**不提交**）。换目录跑用 `--data-dir`。

## 四条设计原则

1. **代码负责记账和执法，模型负责理解和表达。** 名额、门槛、休眠天数、状态流转由代码强制；分类、措辞、追问交给模型。
2. **核心不依赖宿主。** 纯函数，不读时钟、不读环境变量、不发网络请求。宿主可以是 CLI、MCP、Bot，换掉不用重写。
3. **消息是协议不是模板。** 渲染器按 `mode` 出变体：常规 / 虚弱启动 / 考试周 / 中断恢复。
4. **进度是位置，不是百分比。** 只认里程碑和断点，禁止手填数字。

## 不做什么

不做笔记、题库、日历、时间追踪、多用户。它不教你学习，只保证你今天做的三件事是对的、明天接得上。
